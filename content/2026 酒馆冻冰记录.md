# 2026 酒馆冻冰记录


## 现状

自来水结冰后中间有絮状冰，呈白色杂质或云状，偶尔絮状冰会发黄。  
目前处理方式：凿掉异常部分，实际损耗约 50%。

---

## 原因分析

### 白色浑浊（白心 / 云状）

水（尤其是自来水）中溶解有空气（主要是氧气、氮气、二氧化碳等气体）。水冻结时，这些气体无法进入冰晶的晶格结构，会被冰晶"挤"出来形成微小气泡。普通家用冰箱或冰格从四周向中心快速冻结，把气体和杂质都推到中心，气泡散射光线，形成白色杂质或云状（cloudy ice）效果。[[1]](https://physics.stackexchange.com/questions/265958/why-is-ice-made-from-boiled-water-clear)


煮沸（白开水）能有效驱除大部分溶解气体，比直接冷水冻要清晰很多，但无法彻底解决：

- 冷却过程中暴露在空气里，会重新溶解部分气体
- 水中还含有溶解矿物质（钙、镁等硬水离子，即 TDS 总溶解固体），冻结时被冰晶排斥、浓缩在最后冻结的中心或底部，形成白色沉淀或颗粒
- 快速冻结加剧了气泡被捕获的问题
[[2]](https://www.scienceabc.com/eyeopeners/why-are-some-ice-cubes-cloudy-while-others-are-clear.html)
### 黄色絮状（偶发）

原因按顺序如下：

**1. 自来水的杂质基础**  
国内很多地区的自来水（尤其是老旧小区、二次供水或地下水源丰富的区域）含有微量溶解性铁离子（Fe²⁺，亚铁）、锰、有机物（腐殖质）、胶体等。管道锈蚀（老铁管、镀锌管长期积累铁锈）是常见来源。
[[3]](https://www.whkfq.gov.cn/xxgk/fdzdgk/shgysy/ggws/ztggwszs/202503/t20250321_2555707.html)
**2. 煮沸的副作用**  
煮沸能有效去除溶解气体，但无法去除非挥发性矿物质和金属。煮沸过程中：
- 引入氧气并加热，促进 Fe²⁺ 氧化成 Fe³⁺（三价铁）
- 形成氢氧化铁（Fe(OH)₃）等黄色 / 黄褐色细小沉淀或胶体（俗称"黄锈"或"铁絮"）
- 钙镁硬度同步析出白色碳酸钙水垢，混有铁或有机物时整体偏黄
[[4]](https://www.waterconserving.cn/universal/detail/1016)
**3. 冻结浓缩效应（核心）**  
普通冰箱从外向内快速冻结，纯水先结晶成冰晶，把所有溶质（铁化合物、有机胶体、矿物质）不断排斥推到最后冻结的中心区域。此处溶质浓度大幅升高（过饱和），导致沉淀、絮凝，形成肉眼可见的黄色絮状物。这正是"偶尔出现"的根源——源水含铁量越高、管道越旧，概率越大。
[[5]](https://physics.stackexchange.com/questions/265958/why-is-ice-made-from-boiled-water-clear)
> 纯冰本身是透明的，"杂质"主要来自物理过程（气泡和浓缩矿物质），对健康通常无害（饮用水源前提下），但影响外观和高端感。

## 解决方案

### 第一档：日消 ≤ 25 杯（现阶段）

#### 设备现状

200L 冰箱兼任冻冰 + 存冰，一区冻冰（约 100L），一区存冰（约 100L）。全部使用小方格冰（4cm × 4cm，12 颗/盘），每杯最低用冰 6 块（调和 3 块 + 上杯 3 块），每天一轮冻冰周期。

#### 产能估算（参考）

| 环节 | 数值 |
|------|------|
| 冻冰空间 | 约 100L |
| 冰格规格 | 4cm × 4cm，12 颗/盘 |
| 可放冰格数 | 约 20–25 盘（实际排列） |
| 单轮原始产出 | 约 240–300 块 |
| 成品后损耗 | 约 50%（凿掉白心/黄冰） |
| 有效产出 | 约 120–150 块/日 |
| 每杯最低用冰 | 6 块 |
| 可支撑杯数 | 约 20–25 杯/日 |

综合一天一轮冻冰周期，**日消 25 杯以内可稳定承受**（与"20 杯左右可以承受"吻合）。

#### 当前痛点

- **痛点 1（存冰管理）**：只有一个存冰桶，无法实现先入先出——新冰处理完叠在旧冰上方，新冰反而先化水；旧冰压底，需要时反而拿不到。
- **痛点 2（冰质）**：无方向冻法（空间不足），无法从根本上解决白心 / 黄冰问题，目前只能凿掉异常部分，损耗大、效率低。
- 现阶段无法批量产出大方冰、长冰、圆冰（设备成本无法负担）。

#### 冰质处理现状

凿掉异常部分，暂无其他解决方向。

---

### 第二档：日消 25–80 杯（扩产阶段）

**触发条件：** 日均消耗超过 25 杯，或冻冰周期明显跟不上出酒节奏。  
**核心目标：** 日消天花板提升至 80 杯，同时解决冰质问题，降低当前 50% 的处理损耗。  
**预算上限：** ¥2,000 以内。

#### 产能缺口分析

| 指标 | 现状（第一档） | 目标（第二档） |
|------|------------|------------|
| 冻冰空间 | 100L | 200L（增购后） |
| 日原始产出 | 约 240–300 块 | 约 480–600 块 |
| 损耗率 | 50% | 目标降至 ≤25% |
| 日有效产出 | 约 120–150 块 | 约 360–450 块 |
| 可支撑杯数 | 约 20–25 杯 | 约 60–75 杯 |

> **说明：** 80 杯/日是弹性目标。在预算 ¥2,000 内、一天一轮冻冰的前提下，双重优化（增容 + 提质）可稳定支撑 60–75 杯，峰值夜晚可配合商业冰补充到 80 杯。

---

#### 方案 A：单独增购冷冻柜（扩量为主，¥600–1,200）

- 采购一台 100–150L 冷冻柜专门冻冰，现有 200L 冰箱全部改为存冰
- 彻底解决老冰新冰混存问题，先入先出可保障
- 冻冰空间翻倍 → 有效产出约 240–300 块/日 → 约 40–50 杯/日
- **不解决冰质**，损耗仍 50%，距离 80 杯目标仍有明显差距
- 月增电费约 ¥30–50

#### 方案 B：净水器 + 增购冷冻柜（推荐，¥900–1,700）

**净水器（RO 反渗透型，约 ¥300–500）：**
- 可将 TDS 降低 90% 以上，铁离子基本去除
- 黄冰问题从根本消除，白心大幅减少
- 处理损耗从 50% 降至约 20–25%，每日凿冰时间显著缩短

**配合增购冷冻柜（同方案 A）：**

| 环节 | 数值 |
|------|------|
| 冻冰空间（增购后） | 约 200L |
| 预计冰格数 | 约 40–50 盘 |
| 单轮原始产出 | 约 480–600 块 |
| 损耗（净化水后） | 约 20–25% |
| 有效产出 | 约 360–480 块/日 |
| 可支撑杯数 | 约 60–80 杯/日 |

**合计投入：¥900–1,700，在预算范围内。**

#### 方案 C：采购商业冰（冰质最优，成本不可控）

- 当地行情：5.4cm × 5.4cm 清冰，4kg / ¥48 = **¥12/kg**
- 每颗约 144g，每袋约 27–28 颗，约 ¥1.7/颗
- 日消 80 杯 × 6 块（等效换算约 3 颗商业冰/杯）→ 约 240 颗/日 → **约 ¥410/日 → ¥12,300/月**
- **结论：作为主力冰源成本不可控，不适合此阶段。**
- **适用场景：** 仅用于溢价产品线（威士忌 on the rocks、高单价岩石杯鸡尾酒），单独定价覆盖成本，偶发补充峰值夜晚缺口。

| 维度 | 方案 A | 方案 B（推荐） | 方案 C |
|------|--------|------------|--------|

**决策建议：优先推进方案 B。净水器优先落地（成本低、见效快），冷冻柜可随业务量增长再采购，两步分开执行也在预算内。**

### 第三档：商业化批量售冰（向外供冰）

**定位：** 向周边酒吧或餐饮批量供应清冰，从自用延伸为对外销售。

#### 前提条件

- 解决水质问题：接净化水 / 过滤水源，或引入方向冻法设备，保证出冰清澈、外观合格
- 具备稳定大产能：商业制冰机或多台冻冰设备
- 供冰定价、包装、运输 / 取货流程待规划

#### 待核算事项

| 事项 | 状态 |
|------|------|
| 目标客户 | 周边酒吧（规模 / 需求量待调研） |
| 设备投入 | 商业制冰机报价 vs. 产能需求 |
| 成本结构 | 水电 + 设备折旧 + 包装 + 损耗 |
| 定价区间 | 参考本地商业冰市场价 |
| 起供量 / 最低订单 | 待定 |

---

> **优先级备注：** 第三档为远期规划，优先聚焦第一档稳定日常运营，再推进第二档扩产决策。
